## 📖 About

The **devclub store**, a product listing with a search bar, built with **Next.js** and **Tailwind CSS** using a *mobile-first* approach.

## 🎯 What you’ll learn

- The *mobile-first* concept in Tailwind CSS
- Breakpoints (`sm`, `md`, `lg`) to adapt the layout
- A responsive grid: 1 column on mobile, 3 on tablet and 4 on desktop
- Showing and hiding elements by screen size (`hidden sm:block`)
- Adjusting typography per breakpoint

## 🚀 Getting started

> Prerequisite: [Node.js](https://nodejs.org/) 18+

```bash
# 1. Clone the repository
git clone https://github.com/agustinhopneto/yt-responsive-tailwind.git
cd yt-responsive-tailwind

# 2. Install the dependencies
npm install

# 3. Run the project
npm run dev
```

Open **http://localhost:3000** 🎉
